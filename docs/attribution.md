# Attribution

## Upstream

The artwork is [lipis/flag-icons](https://github.com/lipis/flag-icons), vendored rather than
fetched at runtime. The version this pack currently carries is recorded in
`resources/assets/svg/config.json` under `upstream.current_version`, which is also what
[`ichava/icon-sets-sync`](https://github.com/ichava/icon-sets-sync) compares against when it
checks for a refresh.

## A note on flags as data

Flag artwork is politically contested in places, and upstream makes its own calls about which
territories are represented and under which codes. This pack vendors those decisions unchanged and
takes no position on them. Raise disputes with
[upstream](https://github.com/lipis/flag-icons/issues), not here, a fork in this repository would
silently diverge from every refresh.
